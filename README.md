# Elysia with Bun runtime

## Development
To start the development server run:
```bash
bun run dev
```

Open http://localhost:3000/ with your browser to see the result.


# This is a project that is using langchain deep agents to leverage an agent team per requested project. 

Team should consist of :
- 1 Project Manager
- 1 Researcher
- 1 Lead Dev
- 1 Backend
- 1 FrontEnd
- 1 QA


### Project Manager



We are following Test Driven Development design pattern. 
Each new function on backend and frontend needs to be tested with written unit and integration tests.
After each task is done and tests are passing, If it is applicable QA should do E2E tests to test the new feature.
